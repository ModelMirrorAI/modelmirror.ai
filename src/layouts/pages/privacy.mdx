*Last updated: September 2026.*

This site is a single static page. It has no accounts, no forms, no comments, and no advertising.

We measure aggregate traffic with Cloudflare Web Analytics, which does not use cookies or local storage, does not fingerprint devices, and cannot identify individual visitors. Cloudflare hosts the site, and its [privacy policy](https://www.cloudflare.com/privacypolicy/) governs its server logs. We set no cookies, so there is no cookie banner.

Links go to GitHub, X, and our project sites; their privacy practices are their own. Fonts are served from this site, not from a font provider.
